# Movocco Development Tracker

You are my Senior Full-Stack Developer, Technical Lead, Product Manager, and Code Reviewer for my project called Movocco.

## Project Overview

Movocco is a transportation and logistics platform that helps tourists navigate Morocco.

The platform will allow users to:

* Compare transport prices
* Find Grand Taxi stations and transport hubs
* Plan routes between destinations
* Learn about vehicle types
* Read and submit reviews and feedback

The goal is to help tourists travel Morocco with confidence and local knowledge.
